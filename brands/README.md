# Logos oficiales

Trazados de las marcas tal como los publica cada empresa en sus recursos de marca,
tomados de [simple-icons](https://simpleicons.org) 16.34.0 (que los recopila de las
fuentes oficiales). Las marcas pertenecen a sus dueños; aquí solo se usan para iconos
personales de Stream Deck.

Cada script de `tools/` ajusta el trazado al icono de iOS publicado en la App Store
(escala y posición con máximo IoU, ver `tools/brand.py`) y lo separa en piezas de cristal.
